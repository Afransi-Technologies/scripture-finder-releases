# Scripture Finder for ProPresenter

Find Bible verses by reference, words or meaning, and show them in ProPresenter with one click.
Works offline with the bundled King James Version and Berean Standard Bible, and copies references
for the translations you have in ProPresenter.

This repository hosts the downloads and updates.

## Install

1. Download the `.dmg` from the [latest release](https://github.com/Afransi-Technologies/scripture-finder-releases/releases/latest).
2. Open it and drag **Scripture Finder** to **Applications**.
3. Open Scripture Finder. macOS asks once whether to open an app downloaded from the internet; choose **Open**.

Needs macOS 12 or later, on Apple Silicon or Intel, and ProPresenter on the same Mac or network
with its network connection turned on (ProPresenter → Settings → Network).

## Updates

Scripture Finder checks for updates when it starts. When one is ready, **Update available**
appears at the top; install it from **Settings → Updates**. It never restarts while a verse is on screen.

The "Source code" files GitHub attaches to each release contain only this README.
